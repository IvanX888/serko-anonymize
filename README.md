# SERKO Anonymize Pro v9

**Профессиональная анонимизация персональных данных в юридических документах России и Беларуси.**

Работает полностью в браузере: документы никуда не отправляются, сервер не нужен. Откройте `index.html` — и работайте.

---

## Почему это лучше обычных «заменялок»

| Возможность | Обычные инструменты | SERKO Pro v9 |
|---|---|---|
| ФИО в падежах | Только именительный | **Все 6 падежей**, включая «Ковалёвой», «Шушкевичу», «от Кузнеца» |
| Белорусские фамилии | Нет | **-ич/-ук/-ко/-енко** (муж. склоняются, жен. нет) |
| Проверка чисел | По длине | **Контрольные суммы**: ИНН, СНИЛС, ОГРН, УНП, р/с+БИК, карты (Лун), IBAN (mod-97) |
| Номера дел и статей | Маскируются (ломают документ) | **Юридический whitelist**: «дело № 2-1234/2025», «ст. 393 ГК РБ», «договор № 45-Ст» остаются |
| Режимы | Только маски | **Маски / Псевдонимы / С восстановлением** |
| Псевдонимы | — | Реалистичные ФИО, **склоняемые в падеж оригинала** («с Тарасовым Р.Д.») |
| Точность | Неизвестна | **P=100%, R=100%, F1=100%** на тестовом корпусе юр. документов |

## Что распознаёт

**Персона:** ФИО (все падежи, инициалы, подписи «/И.И./», «в лице …»), даты рождения, адреса (включая «зарегистрирован по адресу: …»), телефоны (+7, 8, +375, 80), email.

**Документы:** паспорт РФ (серия/регион), паспорт РБ, **личный номер РБ** (идентификационный номер вида `1204800A001PB2`), ВУ/СТС/ПТС.

**Финансы:** ИНН (10/12, контрольная сумма), СНИЛС (контрольная сумма), ОГРН/ОГРНИП/КПП, **УНП РБ** (контрольная цифра), расчётные счета (ключевание с БИК), БИК, IBAN (mod-97), банковские карты (алгоритм Луна).

**Прочее (опционально):** юр. лица (ООО, ОАО, ЧУП, ОДО, РУП, СООО…), суммы, гос. номера авто, IP/URL/MAC.

## Три режима

1. **Маскирование** — `[ФИО-1]`, `[ИНН-1]`, `[АДРЕС-1]`. Быстро и наглядно.
2. **Псевдонимы** — документ остаётся читаемым: «Гражданин Тарасов Роман Дмитриевич… с Тарасовым Р.Д.». Псевдоним консистентен для каждой персоны и склоняется правильно.
3. **С восстановлением** — маски + JSON-карта соответствий. Исходный текст восстанавливается одной кнопкой. Храните карту отдельно!

## Интерактивный редактор

После обработки вы видите подсвеченный документ:

- **клик** по фрагменту — скрыть/оставить;
- **выделение + «Скрыть выделенное»** — точные границы вручную;
- **отмена / сброс правок**;
- значок **✓** — контрольная сумма сошлась (данные точно настоящие).

## Архитектура

```
index.html          — интерфейс
css/style.css       — темы (светлая/тёмная/системная)
js/
  dictionaries.js   — словари РФ+РБ: 965+ фамилий, имена, отчества, города, улицы, маркеры
  morph-engine.js   — морфологический движок v2: парадигмы склонения, обратный индекс форм
  validators.js     — контрольные суммы: ИНН, СНИЛС, ОГРН, УНП, р/с+БИК, Лун, IBAN, личный номер РБ
  detectors.js      — детекторы всех типов ПД + юридический whitelist
  fio-engine.js     — пайплайн ФИО: якоря → скоринг → персоны → распространение по падежам
  anonymizer.js     — ядро: разрешение пересечений, 3 режима замены, восстановление
  app.js            — логика интерфейса
tests/
  test-cases.js     — корпус юридических документов РФ/РБ
  run-tests.js      — метрики Precision / Recall / F1
```

Модули работают и в браузере (`window.Anonymizer`), и в Node.js (`require`).

## API (для интеграции)

```js
const result = Anonymizer.anonymize(text, {
  mode: 'pseudonym',              // 'mask' | 'pseudonym' | 'reversible'
  types: ['fio', 'inn', 'phone'], // активные типы
  customWords: ['Серко'],         // пользовательские слова (склоняются!)
  stopWords: ['больница']         // не маскировать
});
// result.result  — анонимизированный текст
// result.matches — все совпадения с координатами и причинами
// result.map     — карта восстановления (режим reversible)
// result.persons — найденные персоны

const original = Anonymizer.restore(result.result, result.map);
```

## Безопасность и соответствие

- Все вычисления — локально в браузере, без сети (подходит для конфиденциальных документов).
- Помогает выполнить требования **152-ФЗ «О персональных данных» (РФ)** и **Закона РБ «О защите персональных данных»** при передаче документов третьим лицам.
- Режим «С восстановлением» = обратимое обезличивание; режимы «Маскирование»/«Псевдонимы» без сохранения карты = необратимое.
